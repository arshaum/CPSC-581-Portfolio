# CPSC 581 Portfolio — GitHub Pages

This is the updated static portfolio, including Projects 1 and 2. The requested final sentence in the portfolio AI disclosure has been removed. All paths are relative, so this works as a GitHub Pages project site.

## Publish

1. Extract this ZIP. Create a GitHub repository (suggested name: cpsc581-portfolio). On GitHub Free, use a public repository for Pages.
2. Upload the extracted contents so index.html, project-1.html, project-2.html, prototype.html, and assets/ are at the repository root. Do not upload only the ZIP or an extra parent folder. Include the empty .nojekyll file if using Git.
3. In the repository, open Settings > Pages. Under Build and deployment, select Deploy from a branch, then main and /(root). Save.
4. Wait for GitHub to publish, then use its Visit site link to get the final URL.

GitHub Pages is publicly accessible; this package includes the original team write-ups linked from the portfolio. Review them before public publication. The existing private ChatGPT-hosted portfolio remains available independently.

No npm install or build step is required. Edit the HTML, CSS, and JavaScript directly and commit changes to main to publish updates.

Official setup instructions:
https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
