AN EMERGING DESIGN PHILOSOPHY

Start with experience.
Learn by making.

My approach is still developing. These principles connect my first two projects: making actions understandable, then making guidance understandable across a shared space.

01

Ground imagination
in experience.

Everyday experiences can make playful concepts more understandable. Playing soccer helped me reconsider where damage should occur.

02

Give feedback
a purpose.

Visual changes should help explain what an action did. The wall communicates damage; Ghost Lens communicates tool state and shared guidance. Both need feedback that users can interpret.

03

Let the prototype
challenge the idea.

A working version exposes what a sketch cannot. The Draw-mode review showed why feature checks also need to consider how users move between actions.
